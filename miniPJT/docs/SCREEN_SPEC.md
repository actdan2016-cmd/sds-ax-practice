# 화면 기획 · 입시나침반

> Claude Design으로 화면을 만들 때 그대로 전달할 수 있는 화면 명세입니다. 백엔드는 FastAPI, 계산·조회 화면은 도구를 직접 호출하는 구조화 API, 상담 화면만 에이전트(`POST /query`)를 씁니다.

## 0. 공통
- 사용자: 학부모 (PC·모바일 모두). 입시 용어를 모르는 사람도 읽을 수 있게 짧은 설명 툴팁
- 모든 결과 화면 상단 고정 고지: "과거 입결 기반 참고치 · 5→9등급 환산은 근사 · 현재 추세 유지 가정"
- 학년도 배지: 수치 옆에 `2028 기준` / `2026 입결` 처럼 학년도 항상 표시
- 4년제 / 전문대는 **같은 위계의 색**으로 구분 (우열이 느껴지는 색·크기 차이 금지)
- 학생 실명·학교명 입력란 없음 (별칭만)

## 1. 성적 입력
- 학기 탭: `1-1` `1-2` `2-1` `2-2` `3-1` (입력된 학기만 활성)
- 과목 행: 과목명 · 교과군(국어/수학/영어/사회/과학/한국사/기타) · 학점 · 석차등급(1~5, 비워둘 수 있음) · 성취도(A~E)
- 1학년 공통과목 기본 행 미리 채움 (공통국어·공통수학·공통영어·통합사회·통합과학·한국사·과학탐구실험)
- CSV 업로드 (형식: `data/sample_student_grades.csv`), "예시 학생으로 체험" 버튼
- 희망 학과(선택) · 희망 계열(선택) 입력
- [분석하기] → 2번 화면, [프로필 저장] → 승인 모달(HITL) 후 저장

## 2. 성적 분석 대시보드
- 요약 카드 3개: 누적 평균(전과목) · 국영수사 · 국영수과
- 학기별 평균 추이 꺾은선 (3개 계열)
- 과목×학기 등급 히트맵 (등급 낮은 칸 강조)
- 9등급 환산 구간 막대: 점 추정 + 구간 (예: 2.28 → 약 3.9, 범위 표시)
- 석차등급 없는 과목은 "평균 제외" 회색 표시

## 3. 지원 가능 대학
- 필터: 학과 키워드(유사 학과 자동 확장 표시) · 4년제/전문대 · 전형(교과/종합/전문대수시) · 지역(서울/경기/인천)
- 4열 보드: **상향 / 소신 / 적정 / 안정**
- 카드: 대학명 · 학과(모집단위) · 전형명 · 최근 컷(9등급, 학년도) · 3년 추이 미니 그래프 · 수능최저 유무 · 출처 링크
- 경고 배지: "정성평가 전형" · "70% 컷 미공개" · "반영 방식 상이(우수 학기 반영)"
- 카드 클릭 → 상세: 전형 요약(`admission_plans.csv`) + 입결 표 + 원문 근거 문단

## 4. 보강 과목 추천 (What-if)
- 목표 대학 1~3개 선택 (3번 화면 카드에서 "목표로 설정")
- 격차 게이지: 현재 환산 등급 ↔ 목표 대학 컷
- 과목별 개선 효과 순위 막대: "수학 1등급 ↑ → 반영 평균 −0.06"
- 시뮬레이터: 다음 학기 과목별 예상 등급 슬라이더 → 평균·분류 변화를 즉시 표시 (분류가 바뀌는 순간 강조)
- 연계 권장과목: 희망 학과 핵심·권장 과목과 현재 약한 과목의 겹침 표시

## 5. 학습 로드맵
- 타임라인: 2-1 → 2-2 → 3-1 → 원서(2028년 9월)
- 학기별: 집중 과목 · 선택과목 추천(핵심/권장 구분, 출처) · 체크리스트
- "학교 개설 여부를 담임 선생님께 확인하세요" 안내

## 6. 상담 챗
- `POST /query` 호출. 답변 아래 "근거 보기"(contexts: 문서명·페이지) 접이식
- 개발자 토글: trace(단계별 도구 호출) 표시 — 시연·평가 캡처용
- 예시 질문 칩: "학생부교과랑 종합 차이?" · "간호학과 전문대 반영 방식?" · "2학년 때 어떤 과목 골라야 해?"

## 7. API (초안)
| 메서드 | 경로 | 용도 | 호출 |
|---|---|---|---|
| POST | `/query` | 상담 챗 (과제 표준 규약) | 에이전트 |
| POST | `/api/grades/analyze` | 학기별·누적 평균, 환산 구간 | `calc_school_gpa` · `convert_grade_5to9` |
| POST | `/api/predict` | 대학 분류 보드 | `search_programs` · `lookup_admission_results` · `classify_chances` |
| POST | `/api/simulate` | What-if·과목별 개선 효과 | `simulate_improvement` |
| GET | `/api/programs?keyword=` | 학과 검색 | `search_programs` |
| POST | `/api/profile` | 프로필 저장 (승인 후) | `save_student_profile` |

`/query` 응답 형식: `{"answer": "...", "contexts": [{"doc_id", "text"}], "trace": [{"step", "input", "output"}]}`
