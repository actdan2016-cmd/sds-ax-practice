## 2. 단계별 수집 방법

### Step 1 · 대상 대학·학과 정하기 (30분)
1. 자녀 고1 누적 평균을 아래 §4 표로 9등급 환산합니다. (예: 5등급 2.3 → 9등급 약 3.9)
2. 환산값 ±1 구간에 입결이 걸치는 수도권 대학을 고릅니다. **4년제와 전문대를 섞어** 상향·적정·안정이 고루 나오게 하면 시연이 좋습니다.
   - 4년제: **어디가**(adiga.kr) → 대학별 입시결과/성적분석
   - 전문대: **프로칼리지**(전문대학 입학정보 포털, 한국전문대학교육협의회 운영 — "프로칼리지" 검색) → 대학별 모집요강·입시결과
3. 희망 학과와 인접 학과(예: 컴퓨터공학 ↔ 소프트웨어 ↔ 인공지능 ↔ 전자공학)를 정합니다. 학과명이 대학마다 달라서 `programs.csv` 의 `keywords` 컬럼이 쿼리 확장의 근거가 됩니다. 희망 학과가 없으면 계열(인문·사회·자연·공학·보건 등)로 3~4개를 고르세요.
   - 학과 탐색: **커리어넷**(career.go.kr) 학과정보, 어디가 학과 검색
4. 전문대는 `degree_years`(2·3·4년제, 간호 등은 4년제 학사)를 꼭 적으세요.

### Step 2 · 시행계획·모집요강 PDF 받기 (1시간)
1. 4년제: 입학처 → 공지사항/자료실 → "2028학년도 대입전형 시행계획"
2. 전문대: 입학처 → "2028학년도 수시 모집요강" (전문대는 시행계획보다 모집요강이 더 찾기 쉽고 상세합니다. 2028 수시 요강은 2027년 상반기 공개 → 그 전에는 2027학년도 요강 + 2028 시행계획을 함께 보세요)
3. 찾기 어려우면 "대학명 2028학년도 시행계획" 웹 검색
4. 파일명은 `{대학명}_{학년도}_{시행계획|모집요강}.pdf` 로 통일해 `data/raw/policies/` 에 저장 (doc_id 로 그대로 사용, git에는 안 올라감)
5. 함께 받으면 좋은 것: **학생부종합전형 가이드북**, **선행학습 영향평가 보고서**(같은 입학처 자료실)

### Step 3 · 전형 요약표 채우기 (1~2시간)
PDF를 보며 `admission_plans.csv` 를 채웁니다. 꼭 볼 항목:
- `admission_year`: 문서 학년도 (지금은 2028)
- `track_type`: 학생부교과 / 학생부종합 / 전문대수시
- `eval_method`: 예) 교과100, 서류100, 1단계 서류100 → 2단계 면접 30, 학생부80+면접20
- `grade_eval`: **정량 / 정성 / 혼합** — 5등급제 이후 정성평가로 바꾼 대학이 있어 예측 신뢰도에 직결
- `subjects_reflected`: 반영 교과 (국영수사과 전과목 / 국영수 중 상위 N과목 등) — **보강 과목 추천의 핵심 입력**
- `grade_reflect_rule`: 반영 학기·학년 비율 (예: 전 학기 동일 / 1학년20:2·3학년80 / 우수 2개 학기) — 전문대는 학교마다 크게 다름
- `achievement_reflect`: 성취도(A~E)만 있는 과목 반영 방식 (미반영 / A=1등급 환산 등)
- `csat_min`: 수능최저 기준을 **원문 그대로** 복사 (요약하면 RAGAS faithfulness 검증이 어려워짐)
- `school_recommend`, `interview`
- `source_doc`, `source_page`: 반드시 기록 (출처 인용 가드레일의 근거)

### Step 4 · 과거 입결 모으기 (1~2시간)
1. 각 대학 입학처 → "입시결과" 게시판에서 2024·2025·2026학년도 수시 결과 PDF/엑셀
2. 4년제는 **어디가** 대학별 입시결과, 전문대는 **프로칼리지**·입학처에서 확인
3. 대학마다 공개 기준이 달라요. 4년제는 50%·70% 컷, 전문대는 평균·최저만 주는 곳이 많습니다. 있는 값만 해당 컬럼(`cut_50`, `cut_70`, `cut_avg`, `cut_min`)에 넣고, 없는 값은 비워 두고 `note`에 "70%컷 미공개"처럼 적으세요. **추정해서 채우지 마세요.**
4. `grade_scale` 컬럼에 반드시 `9` 기록 — 에이전트가 5등급 값과 섞지 않게 하는 장치
5. 경쟁률·충원은 **대학알리미**(academyinfo.go.kr, 전문대 포함)에서 교차 확인 가능

### Step 5 · 전공 연계 권장과목 (1시간)
1. 서울대 등 여러 대학이 발표한 "전공 연계 교과이수 과목(핵심·권장과목)" 안내 — "대학명 전공 연계 교과 이수 과목" 검색
2. 각 대학 학생부종합전형 가이드북의 "모집단위별 권장과목" 표
3. 과목명은 **2022 개정 교육과정** 기준 (예: 대수, 미적분Ⅰ, 확률과 통계, 미적분Ⅱ, 기하, 물리학, 역학과 에너지 등). 과목 체계는 **고교학점제 홈페이지**(hscredit.kr)에서 확인
4. 대학별로 다르면 `univ_id`에 대학, 공통이면 `ALL`

### Step 6 · 자녀 성적·학교 교육과정 (20분, 커밋 금지)
1. 자녀 실제 성적은 화면에서 입력하거나 `data/private/student_grades.csv` (형식은 `data/sample_student_grades.csv`)로 관리합니다. **`data/private/`는 .gitignore 대상**입니다.
2. 성적표에서 옮길 항목: 학기, 과목명, 학점, **석차등급(1~5)**, 성취도(A~E). 석차등급이 없는 과목은 `grade_5`를 비워 두세요 (평균 계산에서 제외).
3. 학교알리미(schoolinfo.go.kr)에서 2·3학년 교육과정 편성표 확인 → 로드맵이 "학교에 없는 과목"을 추천하지 않도록 씁니다.

## 5. 보강 과목 시뮬레이션 (simulate_improvement 설계 메모)
- 대학별 반영 평균 = Σ(반영 과목 등급 × 학점) / Σ(반영 과목 학점)
- 과목 X를 앞으로 한 학기 1등급 올렸을 때 효과 ≈ 해당 과목 학점 / (누적 반영 학점 + 새 학기 반영 학점) → **학점이 크고, 반영 과목에 포함되고, 현재 등급이 낮은 과목**이 효과가 큽니다.
- 예 (`sample_student_grades.csv` 페르소나): 고1 누적 105/46 = **2.28**. 2학년 1학기에 다른 과목은 그대로 두고 수학만 3→2등급이면, 2학년 1학기도 23학점이라 가정할 때 누적 평균이 약 0.06(4학점 ÷ 누적 69학점) 내려갑니다. 학기가 쌓일수록 한 학기 개선의 효과는 작아지므로 **빨리 올릴수록 유리**하다는 근거가 됩니다.
- 출력: 과목별 개선 효과 순위 + 목표 대학 70% 컷까지의 격차(9등급 환산) + "현재 추세 유지 시" 고지
