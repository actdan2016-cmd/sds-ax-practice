# SERVICE · 입시나침반 (가칭)
> 고1 학기별·과목별 5등급제 내신으로 **수도권 4년제·전문대학** 지원 가능권을 예측하고, 한 단계 위 대학으로 가기 위해 **어떤 과목을 얼마나 올려야 하는지** 알려주는 Agentic RAG 웹서비스

## 1. 사용자·문제·가치
- **왜 지금 필요한가 (배경)**
  - 2025년 고1부터 고교학점제와 **내신 5등급 상대평가**가 적용된다(누적 1등급 10% · 2등급 34% · 3등급 66% · 4등급 90%). 일부 과목은 석차등급 없이 성취도(A~E)만 기재된다.
  - 대상 학생(2026년 고1)은 **2029학년도 대입**을 치른다. 2029 시행계획은 2027년 4~5월에 공개되므로, 그 전까지 **2028학년도 시행계획을 대용**으로 쓰고 답변에 학년도를 밝힌다.
  - 공개된 과거 입결(2025·2026학년도)은 모두 **9등급 기준**이라, 학부모가 "평균 2.3등급이면 어디까지?"를 판단할 기준이 없다.
  - 2~3등급대 학생은 4년제 교과·종합과 전문대 수시까지 선택지가 넓은데, 정보가 어디가·전문대 포털·대학별 PDF에 흩어져 있다.
- **누구를 위한 서비스인가**
  - 1차: 5등급제 내신을 받은 **고1 자녀(중위권~상위권 경계, 평균 2~3등급대)를 둔 학부모** — 본인 가정과 같은 학교 학부모 모임 10~20가구
  - 2차: 학생 본인, 진로·진학 담당 교사
- **어떤 문제를 푸는가 (한 문장)**
  - "고1 성적표를 받았지만, 이 성적이 수도권 4년제·전문대 중 어디쯤이고, 한 단계 올라가려면 2·3학년 동안 어떤 과목에 집중해야 하는지 근거 있게 판단할 방법이 없다."
- **지금은 어떻게 해결하나**
  - 어디가 성적분석(4년제·9등급 과거 자료 중심), 전문대는 학교별 입학처를 하나씩 확인, 입시 커뮤니티 카더라, 고비용 사설 컨설팅, 시간이 제한된 담임 상담
- **이 에이전트로 좋아지는 점**
  1. **학기별·과목별 성적 입력 → 학점 가중 평균**(전과목·국영수사·국영수과)과 학기별 추이를 자동 계산
  2. 5등급 → 9등급 **환산 근거(누적 백분위)를 구간으로 투명하게** 보여주고 과거 입결과 비교
  3. 희망 학과(유사 학과 포함) 또는 계열 기준으로 **수도권 4년제 + 전문대**를 **상향 / 소신 / 적정 / 안정**으로 분류
  4. **보강 과목 추천**: "어떤 과목을 1등급 올리면 목표 대학 반영 평균이 가장 많이 오르는가"를 학점·반영 과목 기준으로 계산(What-if 시뮬레이션)하고, 한 단계 위 대학까지의 격차를 보여줌
  5. 학과 권장과목을 반영한 **고2·고3 학기별 학습·과목선택 로드맵**
  6. 모든 수치에 **출처(대학명·문서명·학년도)** 인용, 데이터가 없으면 없다고 말함

## 2. 서비스 확장 관점
- **수익 모델**
  - B2C 구독: 학기말 성적 업데이트 시 변화 리포트·보강 과목·로드맵 갱신 (연 4회 + 원서 시즌 집중)
  - B2B: 학원·컨설팅 업체용 상담 준비 보조 도구 (상담 1건당 자료 준비 시간 절감)
  - B2G/학교: 진학 담당 교사용 상담 보조, 교육청 진학지원센터 연계. **전문대 입학처** 대상 지원자 유입 채널(학과 정보 노출)
- **사내 기여 (에듀테크 기업 가정)**: 상담사 1인당 처리 상담 수 증가, 입시자료 갱신 작업을 RAG 인덱스 재빌드로 대체
- **규모**: 학년당 학생 약 40만 명대. 상위 1등급(10%) 밖의 90%가 4년제·전문대를 함께 고민하는 실수요층. 사용 빈도는 학기말 성적 발표(연 4회)와 수시 원서 시즌에 집중
- **대체제와의 차별점**

| 대체제 | 한계 | 입시나침반 |
|---|---|---|
| 어디가 성적분석 | 공식이지만 4년제·9등급 중심, 보강 전략 없음 | 5→9 환산 근거 + 4년제·전문대 통합 + 보강 과목 시뮬레이션 |
| 전문대 입학처 개별 조회 | 학교마다 따로 찾아야 함, 반영 방식 제각각 | 반영 학기·과목 규칙까지 한 화면 비교 |
| 사설 컨설팅 | 고비용, 판단 근거 비공개 | 근거·출처 전부 공개 |
| 범용 챗봇 | 환각, 최신 전형 미반영, 출처 없음 | 공식 문서 RAG + 계산 도구 + 불확실성 명시 |

## 3. 사용 예상 도구·데이터
### 3-1. 도구
처음에는 **1차 도구 3개**만 만들어 에이전트가 도는 것을 확인하고, 평가 루프를 돌리며 2차·3차를 붙인다.

| 단계 | 도구 | 기능 | 입력 → 출력 |
|---|---|---|---|
| **1차** | `calc_school_gpa` | 학점 가중 평균 계산 (성취도만 있는 과목 제외) | 학기별 과목 등급·학점 → 학기별·누적 평균(전과목/국영수사/국영수과)과 추이 |
| **1차** | `lookup_admission_results` | 입결 조회 | 대학·모집단위·전형 → 경쟁률·충원·50%/70% 컷(2025·2026학년도) |
| **1차** | `classify_chances` | 5등급 → 9등급 환산(누적 백분위 구간) 후 과거 컷과 비교 | 평균 등급·대학 → 상향/소신/적정/안정 + 판정 근거 |
| 2차 | `retrieve_admission_docs` | 시행계획 RAG (하이브리드 검색 + 리랭킹) | 질의 → 근거 청크 + 문서명·쪽·학년도 |
| 2차 | `get_recommended_courses` | 학과별 핵심·권장 과목 | 학과 → 과목 목록 + 출처 |
| 2차 | `simulate_improvement` | What-if: 과목별 등급 변화 시 평균·판정 변화, 과목별 개선 효과 순위 | 현재 성적 + 목표 대학 → 과목별 기여도·목표 컷까지 격차 |
| 3차 | `search_programs` | 학과 키워드로 개설 대학 검색 (유사 학과, 4년제/전문대 필터) | "간호" → 대학·모집단위 목록 |
| 3차 | `save_student_profile` (HITL) | 성적·희망학과 장기 저장 (승인 후) | 프로필 → LangGraph Store |

- 5→9 환산은 `grades.py` 함수로 만들어 1차에서는 `classify_chances`가 내부에서 쓴다. 환산만 묻는 질문(평가 2·8·16번)용 `convert_grade_5to9` 도구는 2차에 추가한다.

### 3-2. 분류 규칙 (classify_chances v1, 2026-11-04 확정)
- 학생 환산 9등급(g)과 기준선(c)을 비교한다.
  - c: 2026학년도 4년제는 최종등록자 70% 컷(없으면 50% 컷), 전문대는 **합격자 평균**(최저는 함께 표시)
  - 안정: g ≤ c − 0.5 · 적정: c − 0.5 < g ≤ c · 소신: c < g ≤ c + 0.5 · 상향: c + 0.5 < g ≤ c + 1.0
  - **격차 큼**: g > c + 1.0 → 숨기지 않고 "컷까지 +x.xx 등급"을 보여 주고 보강 과목(What-if)으로 연결
- **4단계 판정은 학생부교과(정량) 전형에만** 붙인다. 학생부종합은 "합격자 내신 참고치"만 보여 주고 판정하지 않는다(정성평가).
- 지역: 기본 목록은 **수도권**, 비수도권은 "수도권 외 참고"로 따로 묶는다.
- 컷이 공개되지 않은 전형(예: 가천대 교과)은 "입결 미공개"로 표시하고 판정하지 않는다.
- 고1 성적만 있을 때는 **"현재 추세 유지 시"** 라는 전제를 항상 표시

## 4. 서비스 정책 (가드레일 요약)
1. **합격 보장·확정 표현 금지.** 모든 예측은 "과거 입결 기반 참고치"이며 5→9 환산은 근사, 고1 성적 기반 예측은 "현재 추세 유지 시" 가정임을 답변마다 명시한다.
2. **출처 없는 수치 금지 · 학년도 혼용 금지.** 컷·모집인원·수능최저는 대학명·문서명·학년도를 인용한다. 2029 자료가 없으면 "2028학년도 기준 참고치"라고 밝힌다. 데이터에 없으면 "확인 불가"라고 말하고 공식 채널을 안내한다.
3. **개인정보 보호.** 학생 이름·학교명·연락처 등은 마스킹하고 트레이스·로그에 원문을 남기지 않는다. 타 학생 성적 조회·비교는 거부한다.
4. **부정 조력·인젝션 거부.** 학생부(세특 등) 대리 작성·허위 기재를 거부하고, 시스템 프롬프트·내부 DB 원본 노출이나 역할 변경 요구에도 정상 서비스를 유지한다.
5. **진로 중립 · 서열 비하 금지.** 4년제·전문대를 우열로 표현하지 않고, "상향/안정"은 합격 가능성 분류일 뿐 학교 가치 평가가 아님을 지킨다.

세부 케이스는 `evaluation/test_queries.csv` 의 guardrail 항목에서 검증한다.

## 6. MVP 범위
구조(CSV·도구·판정 코드)는 학과와 무관하게 만들고, **데이터는 두 계열로 채운 MVP**로 시연한다.

| 계열 | 대학 | 고른 이유 |
|---|---|---|
| **간호** | 4년제 15곳 + 전문대 1곳(동남보건대) | 4년제와 전문대에 같은 학위 과정(4년제 학사, 같은 국가시험)이 있어 "4년제·전문대 함께 비교"라는 차별점을 가장 잘 보여 줌 |
| **컴퓨터공학** | 4년제 11곳 (컴퓨터·소프트웨어 학과가 있는 대학) | 같은 대학 안에서도 계열에 따라 컷이 크게 다름을 보여 줘 학과 무관 구조임을 증명 |

- 데이터: 2028 시행계획(2029 대용), 대학별 5등급 배점표, 2025·2026 입결(어디가·전문대학포털), 권장과목. 수도권 중심에 충청·강원·전북 일부 포함
- 다른 학과 추가: 어디가 입결은 키워드만 바꿔 받고, 시행계획·배점표는 대학 단위라 이미 받은 PDF에서 추출 (`docs/DATA_COLLECTION_GUIDE.md`)
- 학과: 희망 학과 + 인접 학과 (희망 학과 미정이면 계열 단위로 검색)
- 전형: 4년제 **학생부교과 · 학생부종합**, 전문대 **수시 일반고 전형(학생부 위주)**. 정시(수능) 예측은 v2
- 성적 입력: 고1 1·2학기 (고2 학기가 쌓이면 같은 화면에 추가)
- 제외: 실기·특기자·재외국민·논술 등 특수 전형

## 7. 적용 패턴 매핑 (12개 중)
설계 원칙: **계산·환산·분류는 코드가, LLM은 설명만 담당.** 위험 요청은 모델 호출 전 규칙으로 차단한다. 상세 구조는 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

| # | 패턴 | 적용 |
|---|---|---|
| 1 | LCEL + Pydantic 구조화 출력 | 성적 입력 파싱, 대학 추천·보강 과목 결과 스키마 (화면 렌더링용 JSON) |
| 2 | ReAct | 질의에 따라 도구 자율 선택 |
