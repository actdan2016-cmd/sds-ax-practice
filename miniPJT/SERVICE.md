# SERVICE · 입시나침반 (가칭)
> 고1 학기별·과목별 5등급제 내신으로 **수도권 4년제·전문대학** 지원 가능권을 예측하고, 한 단계 위 대학으로 가기 위해 **어떤 과목을 얼마나 올려야 하는지** 알려주는 Agentic RAG 웹서비스

## 0. 도메인 배경 (왜 지금 필요한가)
- 2025년 고1부터 **고교학점제 + 내신 5등급 상대평가** 적용 (누적 기준 1등급 10% · 2등급 34% · 3등급 66% · 4등급 90% · 5등급 100%, 성취도 A~E 병기). 일부 과목(사회·과학 융합선택, 체육·예술·교양 등)은 석차등급 없이 성취도만 기재된다.
- 대상 학생(2010년생, 2026년 고1)은 **2029학년도 대입**을 치른다. 5등급제 두 번째 학년이다.
  - 2029학년도 대입전형 시행계획은 **2027년 4~5월** 공개 예정 → 그 전까지는 **2028학년도 시행계획을 참고 기준(proxy)** 으로 쓰고, 답변에 학년도를 명시한다.
  - 2028년 상반기에는 첫 5등급제 실측 입결(2028학년도)이 공개된다 → 그때부터 환산 없이 직접 비교 가능 (v2 데이터 교체 지점).
- 대학이 공개한 과거 입결(2024~2026학년도)은 전부 **9등급 기준**이라, 학부모가 "평균 2.3등급이면 어디까지?"를 판단할 기준이 없다.
- 수능은 통합형(국어·수학 선택과목 폐지, 통합사회·통합과학)이지만 **등급은 9등급 유지**. 내신 5등급과 수능 9등급이 공존한다.
- 1등급 최상위권이 아닌 **2~3등급대 학생**은 선택지가 4년제 학생부교과·종합, 전문대 수시까지 넓게 걸쳐 있는데, 이 정보가 어디가(4년제)·전문대 포털·대학별 PDF 수십 개에 흩어져 있다.

## 1. 사용자·문제·가치
- **누구를 위한 서비스인가**
  - 1차: 5등급제 내신을 받은 **고1 자녀(중위권~상위권 경계, 평균 2~3등급대)를 둔 학부모** — 본인 가정과 같은 학교 학부모 모임 10~20가구
  - 2차: 학생 본인, 진로·진학 담당 교사
- **어떤 문제를 푸는가 (한 문장)**
  - "고1 성적표를 받았지만, 이 성적이 수도권 4년제·전문대 중 어디쯤이고, 한 단계 올라가려면 2·3학년 동안 어떤 과목에 집중해야 하는지 근거 있게 판단할 방법이 없다."
- **지금은 어떻게 해결하나**
  - 어디가 성적분석(4년제·9등급 과거 자료 중심), 전문대는 학교별 입학처를 하나씩 확인, 입시 커뮤니티 카더라, 고비용 사설 컨설팅, 시간이 제한된 담임 상담
- **이 에이전트로 좋아지는 점**
  1. **학기별·과목별 성적 입력 → 학점 가중 평균**(전과목·국영수사·국영수과)과 학기별 추이를 자동 계산
  2. 5등급 → 9등급 **환산 근거(누적 백분위)를 구간으로 투명하게** 보여주고 과거 입결과 비교
  3. 희망 학과(유사 학과 포함) 또는 계열 기준으로 **수도권 4년제 + 전문대**를 **상향 / 소신 / 적정 / 안정**으로 분류
  4. **보강 과목 추천**: "어떤 과목을 1등급 올리면 목표 대학 반영 평균이 가장 많이 오르는가"를 학점·반영 과목 기준으로 계산(What-if 시뮬레이션)하고, 한 단계 위 대학까지의 격차를 보여줌
  5. 학과 권장과목을 반영한 **고2·고3 학기별 학습·과목선택 로드맵**
  6. 모든 수치에 **출처(대학명·문서명·학년도)** 인용, 데이터가 없으면 없다고 말함

## 2. 서비스 확장 관점
- **수익 모델**
  - B2C 구독: 학기말 성적 업데이트 시 변화 리포트·보강 과목·로드맵 갱신 (연 4회 + 원서 시즌 집중)
  - B2B: 학원·컨설팅 업체용 상담 준비 보조 도구 (상담 1건당 자료 준비 시간 절감)
  - B2G/학교: 진학 담당 교사용 상담 보조, 교육청 진학지원센터 연계. **전문대 입학처** 대상 지원자 유입 채널(학과 정보 노출)
- **사내 기여 (에듀테크 기업 가정)**: 상담사 1인당 처리 상담 수 증가, 입시자료 갱신 작업을 RAG 인덱스 재빌드로 대체
- **규모**: 학년당 학생 약 40만 명대. 상위 1등급(10%) 밖의 90%가 4년제·전문대를 함께 고민하는 실수요층. 사용 빈도는 학기말 성적 발표(연 4회)와 수시 원서 시즌에 집중
- **대체제와의 차별점**

| 대체제 | 한계 | 입시나침반 |
|---|---|---|
| 어디가 성적분석 | 공식이지만 4년제·9등급 중심, 보강 전략 없음 | 5→9 환산 근거 + 4년제·전문대 통합 + 보강 과목 시뮬레이션 |
| 전문대 입학처 개별 조회 | 학교마다 따로 찾아야 함, 반영 방식 제각각 | 반영 학기·과목 규칙까지 한 화면 비교 |
| 사설 컨설팅 | 고비용, 판단 근거 비공개 | 근거·출처 전부 공개 |
| 범용 챗봇 | 환각, 최신 전형 미반영, 출처 없음 | 공식 문서 RAG + 계산 도구 + 불확실성 명시 |

## 3. 사용 예상 도구·데이터
### 3-1. 도구

|---|---|---|
| `calc_school_gpa` | 학점 가중 평균 계산 (성취도만 있는 과목 제외) | 학기별 과목 등급·학점 → 학기별·누적, 전과목/국영수사/국영수과 평균 + 추이 |
| `convert_grade_5to9` | 5등급 → 누적 백분위 → 9등급 환산 (점 추정 + 구간) | 평균 등급 → 백분위 구간, 9등급 환산 구간 |

### 3-2. 분류 규칙 (classify_chances v0)
- 학생 환산 9등급 구간의 중앙값(g)과 최근 연도 70% 컷(c, 없으면 50% 컷) 비교
  - 안정: g ≤ c − 0.5 · 적정: c − 0.5 < g ≤ c · 소신: c < g ≤ c + 0.5 · 상향: c + 0.5 < g ≤ c + 1.0 · 그 밖: 표시 안 함
- `grade_eval`이 정성/혼합인 전형은 분류 옆에 "정성평가 — 등급만으로 판단 어려움" 경고
- 고1 성적만 있을 때는 **"현재 추세 유지 시"** 라는 전제를 항상 표시

## 4. 서비스 정책 (가드레일 요약)
1. **합격 보장·확정 표현 금지.** 모든 예측은 "과거 입결 기반 참고치"이며 5→9 환산은 근사, 고1 성적 기반 예측은 "현재 추세 유지 시" 가정임을 답변마다 명시한다.
2. **출처 없는 수치 금지 · 학년도 혼용 금지.** 컷·모집인원·수능최저는 대학명·문서명·학년도를 인용한다. 2029 자료가 없으면 "2028학년도 기준 참고치"라고 밝힌다. 데이터에 없으면 "확인 불가"라고 말하고 공식 채널을 안내한다.
3. **개인정보 보호.** 학생 이름·학교명·연락처 등은 마스킹하고 트레이스·로그에 원문을 남기지 않는다. 타 학생 성적 조회·비교는 거부한다.
4. **입시 부정 조력 거부.** 학생부(세특 등) 대리 작성·허위 기재, 부정행위 방법 안내를 거부한다.
5. **프롬프트 인젝션 방어.** 시스템 프롬프트·내부 DB 원본 노출, 역할 변경 요구를 거부하고 정상 서비스를 유지한다.
6. **진로 중립 · 서열 비하 금지.** 4년제·전문대를 우열로 표현하지 않고, "상향/안정"은 합격 가능성 분류일 뿐 학교 가치 평가가 아님을 지킨다.

세부 케이스는 `evaluation/test_queries.csv` 의 guardrail 항목에서 검증한다.

## 5. 성공 기준
- **인-아웃 세트 통과율**: 1차 ≥ 60%, 최종 ≥ 85%. 단 **guardrail 카테고리는 100%** 필수
- **RAGAS**: faithfulness ≥ 0.85 · answer_relevancy ≥ 0.80 · context_recall ≥ 0.75 · context_precision ≥ 0.70
- **계산 정확도**: 평균 등급·환산값·What-if 시뮬레이션 값이 수작업 계산과 100% 일치
- **출처 인용률**: 수치가 포함된 답변 100%에 출처·학년도 표기
- **"쓸만하다" 판단 지표 (선택)**: 학부모 3명 이상 시범 사용 후 "담임/진학 상담 준비에 도움이 됐다" 5점 척도 평균 4점 이상

## 6. MVP 범위
- 대학: 수도권 **4년제 8~12개 + 전문대 4~8개** (학생 환산 등급 ±1 구간 중심, 상향·적정·안정이 고루 나오게)
- 학과: 희망 학과 + 인접 학과 3~4개 계열 (희망 학과 미정이면 계열 단위로 검색)
- 전형: 4년제 **학생부교과 · 학생부종합**, 전문대 **수시 일반고 전형(학생부 위주)**. 정시(수능) 예측은 v2
- 성적 입력: 고1 1·2학기 (고2 학기가 쌓이면 같은 화면에 추가)
- 제외: 실기·특기자·재외국민·논술 등 특수 전형

## 7. 적용 패턴 매핑 (12개 중)
설계 원칙: **계산·환산·분류는 코드가, LLM은 설명만 담당.** 위험 요청은 모델 호출 전 규칙으로 차단한다. 상세 구조는 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

| # | 패턴 | 적용 |
|---|---|---|
| 1 | LCEL + Pydantic 구조화 출력 | 성적 입력 파싱, 대학 추천·보강 과목 결과 스키마 (화면 렌더링용 JSON) |
| 2 | ReAct | 질의에 따라 도구 자율 선택 |
| 3 | RAG (하이브리드·리랭킹·쿼리확장) | 시행계획 PDF 검색, 학과명 동의어 확장 |
| 4 | 도구 다중 | 평균 계산 → 환산 → 입결 조회 → 분류 → 시뮬레이션 체이닝 |
| 5 | MCP (선택) | 입결·전형 조회를 MCP 서버로 노출 |
| 6 | 가드레일 | 입력: before_model 규칙 선처리(인젝션·타 학생·대리 작성·보장 문구·범위 밖) / 출력: 코드 + LLM 검사, 재시도 후 거절 |
| 7 | HITL | 학생 프로필 장기 저장 전 승인 |
| 8 | 미들웨어 | PII 마스킹, 긴 상담 이력 요약 |
| 9 | Multi-Agent Supervisor (선택) | 성적분석 / 대학추천 / 보강전략·로드맵 서브에이전트 — 단일 에이전트 완성 후 여유 시 |
| 10 | Plan-Execute · 장기 메모리 | 로드맵 단계 분해, 학기별 성적 누적 |
| 11 | Observability | LangSmith 트레이스 |
| 12 | 평가 | RAGAS + LLM-as-Judge 라운드별 리포트 |
